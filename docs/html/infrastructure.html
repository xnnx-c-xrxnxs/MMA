Common Commands

# Start all infrastructure (run once per dev session)
docker compose up -d

# Check health
docker compose ps

# View LocalStack logs
docker compose logs -f localstack

# Stop (data persists in named volumes)
docker compose down

# Stop AND wipe all data (fresh start)
docker compose down -v
Credentials. LocalStack accepts any non-empty credentials. .env.local provides AWS_ACCESS_KEY_ID=test and AWS_SECRET_ACCESS_KEY=test so the AWS SDK resolves credentials without a real AWS profile.

Setup Scripts

scripts/setup-localstack.ts

Creates DynamoDB tables and SQS queues in LocalStack. Reads .env.local automatically.

Resource TypeNameEnv VarDomain
DynamoDB Tables USERS USERS_DYNAMODB_TABLE_NAME User
PRODUCTS PRODUCTS_DYNAMODB_TABLE_NAME Product
SQS Queues users-events USERS_SQS_QUEUE_NAME User
order-events ORDER_EVENTS_SQS_QUEUE_NAME Order
product-events PRODUCT_EVENTS_SQS_QUEUE_NAME Product 
# Create tables + queues (idempotent — skips if they exist)
pnpm run localstack:setup

# Force recreate (delete + create)
pnpm run localstack:setup:force

# Check existing resources
pnpm run localstack:setup -- --status

scripts/prisma-migrate-all.ts

Runs Prisma migrations for all registered domains. Currently:

DomainSchema PathEnv Var
order-domain packages/order-domain/src/infrastructure/prisma/schema.prisma ORDERS_DATABASE_URL 
# Run all pending migrations
pnpm run prisma:migrate:all
Adding a new Prisma domain. Register it in the PRISMA_DOMAINS array in scripts/prisma-migrate-all.ts. No new VS Code task needed — DB: Migrate All handles all domains automatically.

scripts/ensure-node.js

Cross-platform Node version resolver. Reads .nvmrc (pins Node 24), finds the correct Node binary in nvm directories, and spawns the given command with the right version. All VS Code tasks use this wrapper to guarantee the correct Node version.

Environment Variables

A .env.local file at the workspace root is required for all local development. It is gitignored and must never be committed. Copy .env.local.example to get started.

Per-Domain Tasks

Each domain has a compound task that starts only its services:

TaskStarts
Domain: Start User user-api-service + user-event-handler-service
Domain: Start Product product-api-service + product-event-handler-service
Domain: Start Order order-api-service + order-event-handler-service

Infrastructure-Only Task

Infra: Start All can be run standalone — useful when you're only working on backend code without running services.

Adding a New Service Task

  1. Add a Service: Serve {name} shell task with npx nx serve {project}.
  2. Set isBackground: true with the appropriate problem matcher.
  3. Append to Services: Start All → dependsOn array.
  4. Append to the appropriate Domain: Start {Domain} → dependsOn array.

Port Registry

Claim the next available port when adding a new HTTP API service:

PortServiceEnv VarAPI URL Env Var
3000 user-api-service USER_SERVICE_PORT API_USER_URL
3001 product-api-service PRODUCT_SERVICE_PORT API_PRODUCT_URL
3002 order-api-service ORDER_SERVICE_PORT API_ORDER_URL
3003 auth-api-service AUTH_SERVICE_PORT API_AUTH_URL
3004 file-api-service FILE_SERVICE_PORT API_FILE_URL
Event-driven services don't register ports. They have no HTTP server — don't add {DOMAIN}_SERVICE_PORT or API_{DOMAIN}_URL entries for SQS consumer services.

Node.js Version

Required: Node.js 24 (pinned in .nvmrc). Run nvm use after cloning.

All VS Code tasks are wrapped with scripts/ensure-node.js, which reads .nvmrc and spawns the command with the correct Node version from nvm — even if you haven't run nvm use in your terminal.

Getting Started Checklist

  1. Clone the repository.
  2. Run nvm use (or ensure Node 24 is active).
  3. Run pnpm install.
  4. Copy .env.local.example → .env.local.
  5. Start Docker: docker compose up -d.
  6. Create LocalStack resources: pnpm run localstack:setup.
  7. Run Prisma migrations: pnpm run prisma:migrate:all.
  8. Start all services: run VS Code task Dev: Start All (or Domain: Start {Domain}).

Or simply run the Dev: Start All VS Code task — it does steps 5–8 automatically.
