Old ST Template

A full-stack Clean Architecture monorepo template demonstrating domain-driven design, dual persistence (DynamoDB + PostgreSQL), event-driven communication, cross-domain integration patterns, and a Next.js frontend with typed API clients and React Query. This documentation explains how and why the architecture works — use it as a guide when building new services, extending existing domains, or adding frontend features.

What This Template Demonstrates

  • Clean Architecture with strict layer separation — presentation, application, domain, infrastructure
  • Five backend bounded contexts (User, Product, Order, Auth, Files) plus an internal monitoring tool, with independent domain models and persistence
  • Dual persistence: DynamoDB OneTable (User, Product) and Prisma + PostgreSQL (Order)
  • Four inter-service communication patterns: synchronous ACL, cross-domain events, intra-domain events, and choreography sagas
  • SQS event-driven services with local polling and Lambda-ready handlers
  • Shared contracts package with Zod validation, subpath imports, and discriminated union event schemas
  • Next.js App Router frontend with React Query hooks, typed API clients, and shared UI primitives
  • Expo / React Native mobile app sharing the same data-access hooks and API clients as the webapp
  • Full local development stack via Docker, LocalStack, and VS Code tasks
